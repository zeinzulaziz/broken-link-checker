# Surface brief: public/index.html (Broken Link Checker)

Scope: single-page tool, Operate mode. Audience: mixed — site owners, developers/agencies, SEO/content specialists. Job: paste a URL, scan, work the broken-link list, export.

## Direction contract

THESIS: A dark, instrument-grade work surface for finding dead links — the category's cleanest scanning/reference table done at full polish. Refuses the purple-gradient SaaS template and the terminal-hacker costume; expression lives in palette, type and one signature move, never in layout conventions.

OWN-WORLD: Ink ground (#10151B family, cool slate not navy), raised panels one step lighter with hairline borders, warm off-white text with tinted grey secondary, a single signal-amber accent (#E5A33D family) reserved for the primary action, focus rings and key emphasis. Red/green are state colours only, never decoration. Type: system UI sans for chrome and prose; ui-monospace stack for URLs, status codes and all figures (tabular). Controls are standard web controls rebuilt in this vocabulary. Signature move: a full-width segmented "link-health strip" in the results summary encoding the working-vs-broken share of checked links — data, not ornament.

STORY: Visitor pastes a URL, watches an honest batched-scan readout, scans the summary, filters/copies/hides rows in the table, exports JSON or CSV and leaves. The screen teaches the job in one pass; no account, no setup.

FIRST VIEWPORT: Top bar: drawn broken-link mark + "Broken Link Checker", right side states "Free · No signup" as plain text. Compact intro line, one sentence, not hero-scale. Dominant element: the URL form — oversized field with link glyph, amber "Check links" button, options row (limit pages toggle + value) beneath. Below the fold start: the three-step "How it works" (crawls internal pages → checks every link in parallel → export as JSON/CSV) closing on one honest limits line (HTML-only crawl; results not stored). Results view: summary stats row anchored by the health strip, then the broken-links table with filters.

FORM: brief-pinned direction (dark professional tool), code-led build (Operate surface). seed: none (brief-pinned, no roll run). Raised with one discipline from committed-palette tools: the accent commits beyond the primary button — focus ring, selection, active filter, the health strip's working segment — never as scattered decoration.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
